# 🚀 TaskJs001

📌 **Atividade da disciplina de Linguagem de Programação I**

Este repositório tem como objetivo apresentar uma **overview de JavaScript**, abordando desde a sintaxe básica até manipulações de strings, arrays e objetos. A maioria dos exemplos foi inspirada na [documentação oficial da linguagem (MDN Web Docs)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript), e estão organizados de forma **simples e didática**, facilitando o aprendizado e entendimento de cada recurso da linguagem.

## 🧠 Observações

- Nas questões que envolvem **leitura de dados via teclado**, o objetivo da atividade foi adaptado para o formato de **funções** (`function`), evitando o uso do `readline` para facilitar a compilação no Node.js. (Como utilizar readLine? -> https://nodejs.org/api/readline.html#readline)
- O uso do `prompt()` está **exemplificado apenas na questão Q01_OperadoresAritméticos.js**, servindo como demonstração prática de entrada de dados.

## 📂 Estrutura

As questões estão organizadas por arquivos individuais e cobrem os seguintes tópicos:

- ✅ Operadores aritméticos
- ✅ Declaração e manipulação de variáveis
- ✅ Estruturas condicionais
- ✅ Estruturas de repetição (loops)
- ✅ Métodos de strings
- ✅ Métodos de arrays
- ✅ Objetos e propriedades
- ✅ Funções e boas práticas
- ✅ Classes e herança
- ✅ Criação e ordenação de listas
- ✅ Leitura e exibição de dados

Cada arquivo segue o padrão `Q0X_Titulo.js` e aborda um tópico específico.
